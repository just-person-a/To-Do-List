# To-Do List — Список задач

Простое веб-приложение для управления списком задач. Позволяет добавлять задачи, отмечать их как выполненные, удалять и фильтровать по статусу. Данные сохраняются в браузере и остаются доступными после перезагрузки страницы.

## Функциональность

- **Добавление задач** — создание новых задач через форму.
- **Выполнение задач** — возможность отмечать задачи как выполненные и возвращать их в активное состояние.
- **Удаление задач** — удаление ненужных записей.
- **Фильтрация** — просмотр всех, активных или выполненных задач.
- **Статистика** — отображение общего количества задач, количества выполненных и оставшихся.
- **Сохранение данных** — автоматическое сохранение списка задач в `localStorage`.
- **Обработка ошибок** — уведомления при проблемах с загрузкой или сохранением данных.

## Технологии

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage API

Проект реализован без сторонних библиотек и фреймворков.

## Хранение данных

Для сохранения задач используется `localStorage` — встроенное хранилище браузера.

Данные сохраняются автоматически при добавлении, изменении статуса и удалении задач. Они не теряются при обновлении страницы, но хранятся отдельно в каждом браузере и на каждом устройстве.

## Использование ИИ

Проект разработан с использованием подхода **Vibe Coding** — AI-assisted development, при котором искусственный интеллект выступает помощником на протяжении всего процесса разработки.

В процессе работы использовались следующие инструменты:

- **ChatGPT** — основной инструмент разработки. Использовался для проектирования приложения, генерации HTML-разметки, CSS-стилей и JavaScript-логики с нуля, последовательного улучшения функциональности и интерфейса, проведения Code Review, поиска потенциальных ошибок и объяснения технических решений.
- **GitHub Copilot (VS Code)** — вспомогательный инструмент для небольших изменений в коде: перевода комментариев и названий секций на английский язык, форматирования и улучшения читаемости кода, а также объяснения отдельных конструкций.

**Роль разработчика:**

Разработчик участвовал в постановке задач, выборе и корректировке решений, проверке предложенного кода, самостоятельном запуске и тестировании приложения, а также изучении реализованных механизмов.

ИИ использовался не только для генерации кода, но и как инструмент обучения, анализа и совместной разработки.
